# Practica Swift

Intenta resolver los ejercicios antes de mirar [las soluciones](./Soluciones.swift). Puedes copiar cada solución a un playground o ejecutarlas todas con:

```bash
swift Ejercicios/Soluciones.swift
```

1. **Fundamentos:** escribe `saludo(nombre:)` para que reciba un `String?` y devuelva «Hola, Ana» cuando hay nombre y «Hola, invitado» cuando no lo hay.
2. **Colecciones:** escribe `aprobados(_:)` para devolver únicamente las notas mayores o iguales a 5, ordenadas de menor a mayor. Prueba también con una lista vacía.
3. **Tipos y métodos:** crea una estructura `Contador` con un valor inicial de cero y un método que permita incrementarlo. ¿Por qué necesita `mutating`?

Después, prueba los [miniproyectos](../Proyectos/README.md). Si te bloqueas, vuelve al capítulo correspondiente y compara tu solución: puede haber varias respuestas correctas.
