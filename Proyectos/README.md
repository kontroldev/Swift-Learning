# Miniproyectos

Tres ejemplos pequeños para practicar lo aprendido. Son puntos de partida: lee el código, ejecútalo y después intenta ampliarlo.

1. **Lista de tareas por terminal:** `swift Proyectos/Tareas.swift comprar pan` crea y muestra una tarea. Sin argumentos muestra un ejemplo. La lista vive solo durante la ejecución. Prueba a añadir una operación para marcar una tarea como completada.
2. **Cliente de API:** `swift Proyectos/API.swift` descarga una tarea de prueba de JSONPlaceholder. Necesita conexión a internet. Añade un campo al modelo o gestiona otras respuestas HTTP.
3. **Contador con SwiftUI:** crea en Xcode un proyecto iOS de tipo App con SwiftUI y sustituye el contenido de `ContentView.swift` por [ContadorView.swift](./ContadorView.swift). Ejecuta la app en el simulador. Añade un botón para reiniciar y evita valores negativos.

Los dos primeros se pueden ejecutar con Swift en macOS; el tercero necesita Xcode y una plataforma compatible con SwiftUI.
